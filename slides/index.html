EvoGraph-Quant

A self-evolving ETL agent that learns from sandbox crashes, so only verified data reaches the risk graph.

Daytona hackathon, 31 October 2026

Risk teams cannot hand this data to an outside agent.

  • The taskTurn confidential holdings and alternative supply-chain intelligence into one risk graph.
  • The ruleThe data stays inside. No closed, external coding agents.
  • The gapSmall in-house models write the ETL, and it breaks on the first dirty field.
Why this exists

Cause and effect, from the payload in this repo

Treat the sandbox as the loss function.

  • LossRun the generated script and keep its exit code and output.
  • GradientThe traceback plus every failed check, written as text.
  • ParameterThe system prompt, rewritten each epoch.
  • Commit ruleOnly rows that pass the ground-truth check reach Neo4j.

commit, reason, remember

Neo4j holds only verified rows, and computes the contagion.

UNWIND $rows AS row MERGE (n:Entity {id: row.id})
MATCH p = (src:Entity {tier: $source_tier})-[*1..8]->(h)
WITH p, h, reduce(c = 1.0, r IN relationships(p) | c * r.weight) AS contagion
